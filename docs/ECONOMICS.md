# Экономика

Деньги — целые копейки. Проценты сценария применяются как `base × (100 + pct) / 100` через Decimal, округление статьи до копейки — ROUND_HALF_UP.

Топливо собственного рейса считается по участкам: литры = метры × мл/км / 1 000 000, затем × действующая цена. Округление один раз на маршрут. На тариф подрядчика топливо компании не начисляется.

Фиксированная зарплата начисляется каждому водителю набора за горизонт, даже без рейса. Владение машиной — тоже, даже если машина стоит. Переменная оплата зависит от времени работы маршрута.

Признанная выручка — только выполненные заказы. Сумма невыполненной выручки хранится отдельно и второй раз из результата не вычитается.

Контроль: `data/reference/tiny_economics_expected.json`.
