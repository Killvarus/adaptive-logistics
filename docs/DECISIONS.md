# Решения

## 2026-10-09 — Node.js 24

На машине через winget установился актуальный LTS Node.js 24.20.0, не ветка 22. Vite 6.3.5 и сборка на этой версии проходят. Версия зафиксирована по факту проверки.

## 2026-10-09 — Индексация переменной оплаты

Ползунок оплаты труда один раз умножает и фиксированную ставку за горизонт, и переменную ставку за час. В демонстрационных данных переменная ставка равна 0, поэтому на контрольном примере видна только фиксированная часть: 6 000 ₽ → 6 600 ₽.

## 2026-10-09 — Стили

Токены и общая вёрстка лежат в `frontend/src/styles/tokens.css` и `global.css`. Отдельный CSS-модуль на каждый компонент не заводился.

## 2026-10-09 — CP-SAT

Используется OR-Tools 9.15. `objective_value` и `best_objective_bound` в этой версии — свойства, не методы. Если solver падает, включается локальный поиск с явной подписью `fallback_local_search`.
